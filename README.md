# Webdev-L2-TributePage# Marie Curie — Tribute Page

A responsive tribute page dedicated to Marie Curie, built with plain HTML5 and CSS3 as a freeCodeCamp-style "Tribute Page" project.

🔗 Live demo: open `index.html` in any browser, or visit the published version if you've hosted it online.

## 📁 Project Structure

```
marie-curie-tribute/
├── index.html     # Page markup and content
├── style.css      # All styling
└── README.md      # This file
```

## ✅ Feature Checklist

- [x] Page title with subject's name and a one-line tagline
- [x] Prominent image (sourced from Wikimedia Commons, public domain)
- [x] Biography/tribute section — 4 original paragraphs
- [x] Timeline of key achievements (styled cards, 1867–1934)
- [x] Quote block, styled distinctly from the rest of the page
- [x] 2 background colors used across sections (navy `#0b2545` and cream `#f7f2e9`)
- [x] 2 font styles — Playfair Display (serif, headings) and Lato (sans-serif, body)
- [x] Responsive layout (mobile breakpoint at 600px)

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox-friendly layout, CSS custom properties not required)
- Google Fonts (Playfair Display, Lato) — loaded via CDN link in `<head>`
- No JavaScript, no build tools, no dependencies

## ▶️ How to Run

1. Download or clone this folder.
2. Make sure `index.html` and `style.css` stay in the same folder.
3. Double-click `index.html` — it opens directly in your default browser.

No local server or installation is required; this is a static page.

To edit in VS Code:
1. Open the folder in VS Code.
2. (Optional) Install the **Live Server** extension for auto-reload while editing.
3. Right-click `index.html` → **Open with Live Server**.

## 📚 Content Sources

- Biographical content paraphrased from Wikipedia and general public biographical sources — not copied verbatim.
- Portrait image: Wikimedia Commons (public domain), linked via Wikimedia's stable `Special:FilePath` redirect so the correct file loads regardless of its internal storage path.
